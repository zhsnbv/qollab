Колокольчик уведомлений

Готовые SVG без зависимостей. Двигается только иконка; язычок — вместе с корпусом.

Есть уведомления

20 × 20 px

0 уведомлений

20 × 20 px

Параметры

Цикл
2,6 с, бесконечно. Покачивание с затуханием и короткой паузой.
Углы
0° → 16° → −12° → 8° → −4° → 1,5° → 0°
Easing
cubic-bezier(.4, 0, .2, 1) на старте; cubic-bezier(.37, 0, .2, 1) далее.
Цвет
#999999 → #f8c89d → #999999
Размер
20 × 20 px; viewBox="-32 -32 320 320" — запас для наклонов без обрезки.
Доступность
При prefers-reduced-motion: reduce иконка статична. Название и количество уведомлений задаются кнопке.

Подключение

При unreadCount > 0 используйте bell-active.svg, иначе bell-empty.svg. Счётчик и фон кнопки не анимируются.

<button aria-label="Уведомления, непрочитанных: 3">
  <img src="bell-active.svg" width="20" height="20" alt="" />
</button>

Сохраните оба SVG рядом с вашей страницей и укажите путь в src. Анимация уже внутри SVG — JavaScript для неё не нужен.
