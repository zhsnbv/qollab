# Закреплённые сообщения

На публичном стенде откройте [/all → Чаты → Закрепы](https://qollab.admirably08.workers.dev/all?group=chats&lang=ru#pin-menu). У каждой карточки своя переписка: можно удержать сообщение, выбрать действие, открыть или закрыть список. Обновление страницы восстанавливает исходные состояния.

[Figma: Qollab Mobile App → Chat → Закреплённые сообщения](https://www.figma.com/design/TWZXMxkjeSINavEVUYbxxG/Qollab-mobile-app?node-id=26437-82629). Один столбец на состояние; верхний ряд — светлая тема, нижний — тёмная. Размер каждого экрана — 402 × 820.

| Состояние | Проверка |
| --- | --- |
| Закрепить сообщение | Долгое нажатие → «Закрепить»: меню закрывается, появляются плашка и событие в чате. |
| Один закреп | Под шапкой виден текст без счётчика. Нажатие открывает список. |
| Несколько закрепов | На плашке — последний закреп и счётчик. Для документа без подписи берётся имя файла. |
| Список закреплённых | Свои и чужие сообщения, снятие одного или всех закрепов. |
| В списке остался один | Массового действия нет; после снятия последнего закрепа список закрывается. |
| Открепить через меню | Меню закреплённого сообщения предлагает «Открепить». |
| Все закрепы сняты | Плашки нет, в ленте остаются переписка и системное сообщение. |

Карточки используют ChatRoom, MobileMessageMenu, PinnedBar и PinnedList. Фикстуры задают только начальные данные. В личных и групповых чатах порядок закрепов определяется порядком действий, независимо от времени отправки. Это локальное состояние прототипа.
