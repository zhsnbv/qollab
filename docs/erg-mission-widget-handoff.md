# Миссия и ценности ERG — хэндофф

Источник: https://www.figma.com/design/WkJVrcsyDV5iDSh4KChOGP/News-Feed-Channels?node-id=7241-2511
Иллюстрация: отдельный узел 8106:41088, экспорт из Figma, 324×239 px с границами эффектов. Заголовок и текст миссии — живой HTML. Исходный Figma-файл не изменён.

## Размещение и поведение

- Мобильная главная `/`: постоянный виджет `mission` в горизонтальной ленте. ERG получает новый `ErgMission`; Integra сохраняет свой `IntegraMission`; другие пространства не получают миссию ERG.
- Общая карточка `WidgetCard`: высота **341 px**, шапка 49 px, тело 290 px с учётом рамки. Размеры соседних карточек не меняются. Листание, точки и пользовательский порядок работают через существующий WidgetsContext.
- Название на мобилке находится только в шапке. Полный текст миссии показан без сокращения. Текст 12 px / 1.4; иллюстрация масштабируется пропорционально, высота 112–166 px. Зарезервированное место не меняется после загрузки картинки.
- Веб: `/handoff/publications-web`, правая колонка главной, существующий постоянный виджет `mission`. Полная композиция: шапка, иллюстрация до 316 px шириной, заголовок 16 px, текст 13 px / 1.4. Высота по содержимому (~451 px при ширине карточки 340 px). Требование одинаковой высоты относится к мобильной ленте.
- Виджет информационный: кликов и переходов у ценностей нет. Веб сохраняет перетаскивание и отображение копии в настройках/панели виджетов.
- Картинка локальная `/img/erg/mission-values.png`, временных URL Figma в приложении нет. Alt перечисляет пять ценностей. В тёмной теме CSS invert + hue-rotate + screen адаптирует белую подложку исходного изображения; для промышленной версии можно подготовить отдельный утверждённый тёмный ассет.

## Файлы интеграции

- `src/components/ErgMission.jsx`, `ErgMission.css` — мобильное содержимое.
- `src/components/Widgets.jsx` — выбор варианта по companyId.
- `src/data/widgets.js` — доступность mission для ERG и Integra.
- `src/gallery/publications-web/portal-v2/shell.html`, `portal.css` — веб-композиция, включая копии в настройках.
- `public/img/erg/mission-values.png` — иллюстрация из макета.

## Приёмка

Проверено браузером: ширины 320/375/402/430, общая высота карточек 341 px (допуск округления 0.1 px), полный текст внутри тела, загрузка локального ассета, сохранение Integra, веб в светлой/тёмной теме, отсутствие runtime ошибок. Сборка приложения и Storybook, git diff --check выполнены. В Widgets.jsx остаются прежние предупреждения Fast Refresh об экспорте вспомогательных функций.

Проверка на устройстве: открыть ERG → Главная → перелистать миссию и соседние виджеты; проверить, что блок под лентой не смещается. Переключить Integra и убедиться, что отображается её фирменная миссия.
