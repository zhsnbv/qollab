# Уведомления чата — QM-2492

Требования: https://jira2.erg.kz/browse/QM-2492 (комментариев нет), замечания в родительской QM-2093. QM-2514 не входит в эту доработку.

- Существующий ряд действий и нижний лист сохранены. Действие «Звук» уточнено до «Уведомления».
- В личном чате два режима: включены / отключены. В группе дополнительно «Только упоминания». Отдельного режима «без звука» нет.
- Текущий пункт отмечен галочкой, доступен через aria-pressed. При смене: мгновенный выбор, анимация галочки 280 мс, затем закрытие. Повторные нажатия во время подтверждения заблокированы. Reduced motion отключает анимацию.
- При ошибке старый режим сохраняется; нижний снекбар предлагает повторить именно неудавшийся выбор. Повторная ошибка снова доступна для повтора.
- Список и профиль используют общий режим: @ для упоминаний, зачёркнутый колокольчик для отключённых уведомлений. Включённый режим не добавляет значок в список.
- Выбор сохраняется локально, синхронизируется между вкладками одного браузера. Реального API уведомлений, push-доставки и синхронизации устройств у прототипа нет.
- При запрещённых уведомлениях показывается поясняющий диалог. Переключатель в экране разрешений — демонстрационный; реальные разрешения браузера/ОС не изменяются.

## Проверка

Открыть локальный прототип и пройти демонстрационный вход, если нужен (тестовый номер +7 700 000 00 00, любой шестизначный код).

1. `/group`: Уведомления → Только упоминания → вновь открыть меню; галочка на выбранном пункте.
2. `/chats`: у PR01DEV + ROBOTS значок @; после перезагрузки сохраняется.
3. `/person`: в меню нет «Только упоминания»; изменение не затрагивает группу.
4. `/group?notificationError=1`: первая смена режима завершается ошибкой; «Повторить» применяет выбор. Offline продолжает возвращать ошибку.
5. `/group?notificationPermission=denied`: нажатие на уведомления открывает диалог запрета. Также доступно отключение демонстрационного разрешения через `/settings/permissions`.
6. `/settings` → оформление → тёмное; повторить меню и ошибку.

`node --test src/utils/chatNotifications.test.js` проверяет ключи чатов, изоляцию и сохранение режимов, повреждённое хранилище и ошибку записи.
