# QM-2611 — реакции и просмотры на вебе

Обновление 14 октября 2026: компактное меню, единая строка активности и вложенный список. WebMessageMenu подключён к основному и компактному чатам portal-v2; handoff использует тот же компонент. Данные остаются демонстрационными.

- Основной веб-чат: `/handoff/publications-web?section=chats`.
- Состояния: `/handoff/reaction-details`.
- Все 24 кадра: `/handoff/reaction-details?view=board`.
- Один кадр: `/handoff/reaction-details?view=frame&state=list&theme=dark`.
- Figma: https://www.figma.com/design/TWZXMxkjeSINavEVUYbxxG?node-id=26123-7074
- Связанный мобильный handoff QM-2604: `/handoff/read-receipts`.

## Поведение

Меню и панель быстрых реакций шириной 232 px. Действия высотой 32 px, шрифт 12.5 px, иконки 16 px. Верхняя строка — «6 реакций · 3 прочитали», либо только доступная часть. Нулевые и недоступные счётчики скрываются. Прочтения доступны автору, реакции — всем участникам.

Наведение, клик или клавиша → открывают рядом с меню панель шириной 288 px. У правого края она раскрывается влево. Фон не затемняется, диалог не создаётся. Между пунктом меню и панелью можно провести курсор; задержка закрытия 180 мс защищает от случайного ухода. Esc / ← закрывают вложенный список и возвращают фокус в его строку. Повторный Esc и клик снаружи закрывают меню. Кнопка закрытия списка доступна с клавиатуры. Внутри длинного списка работает независимая прокрутка.

Один участник — одна строка, даже если он прочитал и поставил реакцию. Реакторы идут первыми, затем прочитавшие без реакции. Сохраняются оба времени с компактными обозначениями реакции и прочтения. Аватар 32 px, имя 13 px, эмодзи 18 px. Общий счётчик участников — уникальные люди; два счётчика в меню не суммируются.

В личной переписке сверху меню — только галочки и «Вчера, 16:35». Это обычный текст: без шеврона, кнопки, фокуса и отдельного экрана истории просмотров.

Капсулы сообщений используют существующие компоненты. Клик ставит/снимает свою реакцию; другая реакция заменяет предыдущую свою. Шесть быстрых реакций и «+» сохранены. В основном и компактном чате работают существующие reply/copy/edit/pin/forward/delete/select. В статическом handoff остальные действия остаются демонстрационными. Пикер общий с QM-2591, поиск и выбор изменяют своё событие реакции; чужие реакции не удаляются.

## Сценарии

| state | Содержание |
| --- | --- |
| menu | Своё сообщение: одна строка реакций и прочтений |
| one-reader | Один прочитавший и несколько реакций |
| incoming | Чужое сообщение: только реакции |
| list | Совместный вложенный список без дублей |
| single | Один реактор |
| long | 24 реакции, прокрутка |
| readers-one | Один прочитавший, без реакций |
| readers-list | Несколько прочитавших |
| readers-long | 24 прочитавших, прокрутка |
| no-readers | Только реакции |
| no-reactions | Только прочтения |
| personal | Личный чат: статичная дата и галочки |

Все сценарии имеют светлую и тёмную тему, размер кадра 1440×900.

## Проверки и выпуск

Модель: авторские права прочтений, уникальные участники, сохранение двух времён, счётчики, реакция/toggle, порядок и короткие даты. Браузер: компактная геометрия, hover/click/keyboard, смена стороны у края, длинный список, личная дата без перехода, обе темы. Перед выпуском — focused oxlint, node tests, `npm run build:all`, `git diff --check` из отдельного чистого worktree. Посторонние изменения других задач в основной рабочей папке в выпуск не входят.
