## Решения для разработки

1. **0 прочитавших:** строка отсутствует целиком. Не показываем серую заглушку, пустой экран и переход к нему. Существующие действия меню остаются на месте.
2. **Переход:** отдельная строка над действиями меню, двойная галочка слева и шеврон справа. Вся строка нажимается; минимальная высота 56 px. Она открывает отдельный экран «Просмотры сообщения». Кнопка «Назад» возвращает в чат с сохранённым положением сообщения, меню закрыто.
3. **Темы:** все 11 сценариев доступны в светлой и тёмной теме, итого 22 экрана 402 × 820. Используются существующие семантические токены проекта.
4. **Граница количества:** ровно 1 → `Прочитано <время>`, например `Прочитано вчера в 16:35`. Ровно 2 и любое большее число → `Просмотров сообщения: N`, без времени в меню. Автор сообщения не включается в счётчик.
5. **Большой список:** обычная вертикальная прокрутка внутри экрана, закреплённая шапка. Без страниц и кнопки «Показать ещё». Проверочный сценарий содержит 94 человека. В продукте список можно виртуализировать без изменения поведения, если это потребуется для значительно больших групп.
6. **Сортировка:** по времени прочтения, новые сверху. При одинаковом времени — по имени (русская локаль), затем по стабильному ID для полного совпадения имён. Совпадающее время не изменяется искусственно.
7. **Иконка:** тот же `Checks` из `@phosphor-icons/react`, который уже используется в `StatusTicks` компонента `Message.jsx`. Семантический цвет `--color-primary`; размер в списке 20 px, в метаданных сообщения остаётся существующий 15 px.
8. **Авторство и 1:1:** строка доступна только автору на своём сообщении, в группе и личном чате. В 1:1 в списке только собеседник. На чужом сообщении строки нет.
9. **Состав списка:** только реальные прочтения. Нет секции «Доставлено, не прочитано», счётчика непрочитавших, времени доставки или придуманного индивидуального времени каждого сообщения. Время берётся из события, которое отдаст backend.
10. **Длинные имена:** переносятся внутри строки и остаются читаемыми полностью; высота строки растёт. Без аватара показываются инициалы. Время и галочка остаются отдельными элементами.

## Границы реализации

Это изолированный кликабельный дизайн-прототип на демонстрационных данных. Он не вызывает API и не подключён к основным чатам. Обычные действия меню показывают подпись о демонстрации; целевой переход «Прочитано» и возврат работают. Фиксированная дата примеров — 14 октября 2026, часовой пояс Asia/Almaty. В реальной интеграции `now` и часовой пояс должны приходить из среды пользователя.

Новый backend-метод и проверка авторства на сервере описаны в приложенном ТЗ, но не реализованы в этом frontend-прототипе. После проверки пользователя предстоят публикация согласованных изменений в GitHub/Cloudflare, перенос состояний в указанную Figma и согласование интеграции с QM-2611. Комментарий в Jira не отправлялся; решения выше готовы для переноса после согласования.
