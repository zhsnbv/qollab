# Qollab — интерактивный прототип (мобилка)

Кликабельный прототип кор-разделов Qollab на React + Vite. Открывается в браузере,
на телефоне ведёт себя как нативное приложение (Add to Home Screen).

## Запуск

```bash
npm install
npm run dev
```

Дев-сервер поднимется на http://localhost:5173.

### Открыть на iPhone (в одной Wi-Fi сети)

1. Запусти с флагом host: `npm run dev -- --host`
2. На айфоне в Safari открой `http://<IP-мака>:5173` (текущий IP мака: **192.168.100.170**,
   т.е. `http://192.168.100.170:5173`). IP может смениться — смотри вывод Vite (строка Network).
3. Для «нативного» вида: в Safari → Поделиться → «На экран Домой». Иконка появится как приложение,
   откроется на весь экран без адресной строки.

Если не открывается — проверь, что телефон и мак в одной сети и macOS-файрвол не блокирует node.

## Структура

- `src/styles/tokens.css` — дизайн-токены (цвета, отступы, радиусы) как CSS-переменные.
  Единый источник правды. Фирменный оранжевый ERG: `--color-primary: #ef7f1a`.
- `src/components/` — общие компоненты:
  - `BottomNav` — нижняя навигация (5 табов, активный в цвете, бейдж на Чатах)
  - `TopBar` — верхняя панель (заголовок/лого + экшены)
  - `TabLayout` — обёртка кор-раздела: топбар и навбар жёстко зафиксированы (скролл только
    у `.scroll-area`; body заблокирован от скролла/резинки, чтобы бары не уезжали на iPhone);
    учтён safe-area (вырез сверху, домашний индикатор снизу); тень топбара при скролле
  - `Skeleton` — анимированные скелетоны загрузки (шиммер) для каждого раздела,
    показываются при каждом переходе на таб (`useSkeleton`)
- `src/screens/` — экраны:
  - `Home` — Главная (готов): поиск, сторис, сервисы, избранное, промо, миссия и ценности,
    публикации, актуальное, кнопка ERG FM
  - `Chats` — Чаты (готов): системные записи, бот ERGiz, люди, статусы, индикаторы контента,
    бесконечная мок-лента (randomuser.me)
  - `Posts` — Новости (готов): переключение Публикации ↔ Мероприятия, выбор канала
    (оранжевое кольцо у выбранного, «Все каналы» или любой), лента в стиле Medium
    (лайк/комменты/репост · закладка/ещё, интерактивные лайк и сохранение),
    бесконечная мок-лента (пары «заголовок ↔ фото» ERG, `public/img/posts/news`),
    шапка выбранного канала («Перейти в канал», как в Medium),
    вид Мероприятий (9 карточек с ленивой загрузкой, дата, организаторы, «Подробнее»)
  - `Services` — Все сервисы (готов): 4 категории, переключатель список/сетка в топбаре
  - `Profile` — Профиль (готов): шапка с аватаром, уровень/ранг, баланс, корпоративные
    и персональные данные, показатели, сертификаты

## Что дальше (по фазам)

**Фаза 1:** каркас + навигация + Главная и Чаты. ✅
**Фаза 2:** Публикации, Сервисы (list/grid), Профиль. ✅ Осталось: роли, поиск, сторис-вью, bottom sheets.
**Фаза 3:** живость — pull-to-refresh (3 фазы), переходы между экранами, скелетоны загрузки, splash.

## Иконки

Ключевые иконки — оригинальные из Figma: нижняя навигация — плоские монохромные PNG @4x
(`public/img/nav`, два состояния: оранжевые активные / серые неактивные, каждая ровно
24×24 канвас для консистентного размера), остальные — SVG (`public/img/common`,
`public/img/profile`, `public/img/services`).
В экспортированных SVG вычищены запечённые фоны контекста (не трогая rect внутри clipPath —
иначе иконка исчезает). Второстепенные (стрелки, поиск, плюс) — Phosphor Icons.

**Фаза 3 начата:** скелетоны загрузки ✅, бесконечные ленты в Новостях и Чатах ✅,
тактильность (opacity при нажатии, scale-bounce у табов) ✅, тень топбара при скролле ✅.

## Интеракции

- `.pressable` / `.press-scale` в `tokens.css` — базовые классы для тактильного отклика;
  точечно у кликабельных строк добавлены `:active { opacity }` / `scale`.
- Табы навбара делают eле заметный scale-bounce при нажатии (spring cubic-bezier).
- Иконки таббара — по два PNG-состояния (цветное активное / серое неактивное),
  фон `#F4EFEA` выбит flood-fill'ом от краёв (белые детали иконок сохранены — они `#FFFFFF`).

## Картинки

Все ассеты (аватары, лого, иконки сервисов, миниатюры) экспортированы из Figma
локально в `public/img/{common,home,chats,posts}` — временных ссылок Figma в коде
больше нет, ничего не протухает.

## Стек и связь с продом

Vite + React + react-router-dom. Мобилка Qollab — React в WebView, так что этот
код архитектурно совпадает с продом. Платформенные различия iOS/Android
подключаются через `data-platform` на корне + оверрайды токенов (следующий этап).
