## Architecture Overview

React 19, Vite 8, React Router 7. Чистый chatThemeCatalog нормализует пресеты и сохранение. useChatAppearance связывает каталог с CompanyContext и settingsPreferences. Общий ChatWallpaper используется в плитке, настройках и настоящем чате. Message и MessageReactions задают реальную геометрию. MobileMessageMenu переносит тему в portal-превью. Общая тема приложения хранится отдельно как qollab.theme.

## Potential Gotchas

- Аудит цветов по умолчанию пишет в v7: передавать новую папку явно.
- Тест ожидает video=null: обновить ожидание при подключении настоящего клипа.
- Portal теряет наследование: long tap проверять отдельно на rich content.
- Старый глобальный wallpaper относится только к ERG.
- Select пока toast. Визуальный стенд не заменяет action workflow.
- Clipboard и autoplay имеют реальные ошибки; кэш и диск остаются демо.
