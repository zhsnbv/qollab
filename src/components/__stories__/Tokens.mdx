# Токены

Значения читаются из подключённых стилей прямо сейчас: переключите тему или
пространство в верхней панели — карточки пересчитаются.

<TokenGrid />

## Шкала отступов

Шаг сетки — 4 пикселя: `--space-1` … `--space-8` дают 4, 8, 12, 16, 20, 24, 32.
Между блоками — 8, внутри карточки — 16–20.

## Радиусы

- `--radius-sm` 8 — плитка внутри карточки
- `--radius-md` 12 — подложка иконки, поле ввода
- `--radius-lg` 16 — карточка, шапка профиля
- `--radius-xl` 20 — верхние углы листа снизу
- `--radius-pill` — пилюли, крупные кнопки, аватарки

Вложенный элемент скруглён слабее родителя: карточка 16 — плитка внутри 8.
