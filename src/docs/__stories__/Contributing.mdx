# Как добавлять новое

## Порядок

1. **Найди паттерн.** Меню — `ActionSheet`. Выбор с подтверждением — `StatusSheet`
   как образец. Список данных — `.data-list`. Плитки — `.stat-card`. Новый
   компонент нужен реже, чем кажется.
2. **Возьми токены.** Ни одного hex в новом коде, кроме палитры статусов.
3. **Проверь обе темы.** Тёмная — не инверсия: проверь контраст акцента и границ.
4. **Проверь пространства.** Экран не должен ломаться при `data-company="integra"`.
5. **Впиши класс шапки** в общий список в `tokens.css`, если экран новый, —
   иначе у него не будет ни тени при скролле, ни общей высоты.
6. **Отступ между блоками 8**, внутри карточки 16–20.
7. **Тексты — по разделу «Редактура».**
8. **Заведи историю.** Без неё компонента нет в библиотеке, а значит его не
   найдут и напишут заново.

## Как писать историю

Истории рендерят компонент из `src/components`, а не его копию. Это правило,
а не привычка: копия расходится с проектом на первой же правке и начинает
врать разработчику.

```jsx
import ActionSheet from '../ActionSheet';

export default {
  title: 'Молекулы/Лист действий',
  component: ActionSheet,
  parameters: { device: 'full' },
};

export const Обычный = {
  render: () => <ActionSheet title="Звук" items={[...]} onClose={() => {}} />,
};
```

- **Раздел** — по атомарному принципу: `Атомы` (неделимое), `Молекулы`
  (сборка из атомов), `Организмы` (самостоятельный блок экрана), `Экраны`.
- **Имена на русском** — библиотеку читают дизайнеры, а не только разработчики.
- `parameters.device: 'full'` — если история показывает оверлей, лист или
  что-то во всю высоту.
- `parameters.route` — стартовый адрес для истории экрана; принимает строку
  или объект `{ pathname, state }`, если экран ждёт данные в `location.state`.
- Данные бери из `src/data`, а не выдумывай: в историях должны быть те же
  имена и тексты, что увидит человек в приложении.

## Чек-лист перед сдачей экрана

- [ ] Тень шапки появляется при прокрутке и видна над карточками
- [ ] Высота шапки 64 + безопасная зона
- [ ] Листы снизу закрываются крестиком и свайпом
- [ ] Скелетон повторяет реальную композицию
- [ ] Пустое состояние объясняет, что здесь появится
- [ ] Цифры табличные (проверь кнопки — им нужно наследование)
- [ ] Обе темы, оба пространства
- [ ] Необратимое действие спрашивает подтверждение
- [ ] Заведена история

## Известные долги

- `ChatProfile` остался старым экраном для групп при `PROFILE_V2 = false`;
  после отказа от флага его можно удалить.
- Корпоративные данные у коллег одинаковые — в данных нет полей на человека.
- Иконки из двух наборов: Fluent (действия, листы, вкладки) и Phosphor
  (навигация, шевроны, стрелки). Смешение осознанное, но при росте стоит
  свести к одному.
