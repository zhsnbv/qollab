# Сетка, радиусы, тени

## Отступы

<SpaceScale />

Шаг — 4 пикселя, ступени 4, 8, 12, 16, 20, 24, 32.

**8 — между блоками.** И между карточками, и между плитками внутри карточки:
плитка со своей рамкой и фоном — такой же блок. Долго держалось иначе — баланс
на 16, задачи на 8, — и два одинаковых по устройству ряда выглядели разными.

**16–20 — поля карточки:** `.pcard` — 20 по вертикали, 16 по горизонтали.
Поля экрана — 16.

Значение не из шкалы — повод перепроверить макет, а не добавить переменную.

Горизонтальные поля 16 держатся на всех экранах, включая шапки листов: заголовок
слева на 16, крестик справа на 16. Раньше каждый лист отбивал заголовок
по-своему, и они не выстраивались друг под друга.

## Радиусы

<RadiusGrid />

Вложенный элемент скруглён слабее родителя: карточка 16 — плитка внутри 8.
Обратное сочетание выглядит как ошибка вёрстки, даже когда сделано нарочно.

## Тени

<ShadowGrid />

Теней четыре, и каждая привязана к слою, а не к «важности»: чем выше слой,
тем шире и мягче размытие. Тень шапки появляется только при прокрутке — на
нетронутом экране шапка сливается с контентом, и это правильно.

Переменных под тени пока нет: значения стоят по месту применения. Это долг —
при добавлении пятой тени первым делом стоит завести `--shadow-*`.

В Safari тень листа была не главной проблемой: `backdrop-filter` у таб-бара
создаёт свой слой и всплывает над затемнением. Поэтому при `html.scrim-open`
фильтр гасится, а таб-бар получает `isolation: isolate`.

## Высота шапок

Все шапки одной высоты — `min-height: calc(64px + env(safe-area-inset-top))`.
Отступ считается через `calc(var(--space-3) + env(safe-area-inset-top))`, а не
через `max(...)`: с `max` на устройствах без выреза шапка становилась ниже, и
экраны скакали при переходах.

Список классов шапок живёт одним селектором в `tokens.css`. Новый экран
дописывается туда — отдельного правила ему не нужно.
