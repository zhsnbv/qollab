# Типографика

Один шрифт на всё приложение — **Inter Variable**, подключён локально пакетом
`@fontsource-variable/inter`. До этого он был указан в стеке, но не загружался,
и интерфейс рисовался системным шрифтом: буквы шире, строки выше, макет ехал.

## Шкала

<TypeScale />

Размеры не произвольные: шесть ступеней покрывают все экраны. Если для нового
блока «не хватает размера» — почти всегда нужен не новый кегль, а другой вес
или цвет.

## Начертания

- **700** — заголовки экрана и листа
- **600** — заголовки блоков, кнопки, активные вкладки
- **400** — текст, подписи, значения

Промежуточных весов нет: 500 и 600 рядом различаются хуже, чем 400 и 600,
а вариантов даёт вдвое больше.

## Цифры — табличные, везде

<TabularDemo />

Правило действует на весь проект: `font-variant-numeric: tabular-nums` стоит
на `body`. Одна оговорка — кнопки, поля и `select` получают от браузера
собственный `font`, поэтому наследование им прописано явно:

```css
button, input, textarea, select {
  font-family: inherit;
  font-variant-numeric: inherit;
}
```

Без этого счётчики в плитках профиля прыгали при обновлении: пропорциональная
единица вдвое уже остальных цифр.

Табличные цифры не должны выглядеть моноширинными — Inter меняет только
ширину цифр, буквы остаются прежними.

## Каретка

Акцентная везде, где можно печатать:

```css
input, textarea, select, [contenteditable] { caret-color: var(--color-primary); }
```

Правило глобальное — включая `contenteditable`, потому что поле ввода
сообщения сделано именно так. Системная синяя каретка выбивалась из темы ровно
там, где взгляд и так сфокусирован.

## Межстрочное

- Заголовки — 1.2
- Текст и сообщения — 1.35
- Подписи в одну строку — без переопределения

## Перенос

Длинные имена и названия групп обрезаем многоточием в одну строку
(`text-overflow: ellipsis`), а не переносим: строка списка должна быть
одной высоты у всех.
