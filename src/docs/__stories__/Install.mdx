# Установка

Библиотека не отдельный пакет: она собирается из приложения. Чтобы работать
с компонентами, достаточно клонировать репозиторий.

```bash
npm install
npm run dev        # приложение, http://localhost:5173
npm run storybook  # библиотека, http://localhost:6006
```

Сборка на прод кладёт библиотеку внутрь приложения, по адресу `/storybook/`:

```bash
npm run build:all
```

## Что где лежит

- `src/styles/tokens.css` — переменные светлой и тёмной темы, общие классы
  шапок, карточек, листов
- `src/styles/companies.css` — переопределения под рабочие пространства
- `src/components` — компоненты и их CSS рядом
- `src/components/__stories__` — истории компонентов
- `src/screens` + `src/screens/__stories__` — экраны и их истории
- `src/context` — компания, вход, избранное
- `src/data` — данные прототипа
- `src/utils` — жесты, клавиатура, тема
- `docs/design-system.md` — та же спецификация текстом, для чтения без запуска

## Зависимости, на которые опираются компоненты

- `react` 18 и `react-router-dom` 6 — оверлейная навигация построена на
  `location.state.background`
- `@fluentui/react-icons` — действия, листы, вкладки
- `@phosphor-icons/react` — навигация, шевроны, стрелки
- `@fontsource-variable/inter` — шрифт подключён локально; в стеке он был
  указан и раньше, но не загружался, и интерфейс рисовался системным

## Перенос в другой проект

Компоненты не привязаны к бэкенду, но привязаны к трём вещам: переменным из
`tokens.css`, обёртке `.device` (в неё портируются листы и тосты) и роутеру.
Переносить нужно вместе с ними — иначе компонент отрендерится, но окажется
бесцветным и без оверлеев.
